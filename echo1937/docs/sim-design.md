# 《回声 1937》第二版设计：会自己运转的城市

> 状态：草案 v0.1，待评审。数值都是初始值，M1 跑起来后按实测调。

## 0. 一句话

1937 年的洛杉矶是一座会自己运转的城市。你的分身在里面过日子，按自己的性格和处境走进不同的剧情分支和任务，你用上帝视角看她每天的漫画。想亲自玩的时候随时接管，用地图、动作菜单和检定，像 GTA 加模拟人生那样操作她。

**设计原则**

1. **规则决定发生什么，AI 只负责演出来。** 世界状态（时间、地点、数值、关系、线索、任务）由规则计算，AI 只把确定的事实写成台词和分镜。
2. **世界不等你。** 人物有自己的日程和目标，有些事到点就会发生，错过了就是错过了。
3. **每个选择都留下痕迹。** 选择会改数值、关系、物品或任务状态，会影响之后能触发什么。
4. **托管和接管是同一个人。** 分身自主的时候也按同一套规则行动，接管只是由你来选动作。分身会慢慢学你的习惯。
5. **表现层是漫画。** 一件事画 1–3 格，平常的事一句话带过。

## 1. 已经定下的决策

| 问题 | 决定 |
| --- | --- |
| 一回合多长 | 一个时段 2–3 回合，一回合约 1–2 小时 |
| 上帝视角看谁 | 只看她（主角分身） |
| 接管时怎么操作 | 只用动作菜单，不做自由输入 |
| 失败的尺度 | 可以被解雇、被警察带走问话、被赶出派对、关系破裂、错过线索导致坏结局；主角不会死，不被羞辱，沿用现有内容边界 |
| 故事卡谁来写 | 主线、支线由编剧写骨架，AI 起草细节；日常小事件允许 AI 即兴补位 |
| 现实时间模式 | 要，排在 M4 之后：离开期间世界按真实时间继续，回来看"她今天过得怎么样" |

## 2. 体验总览

### 2.1 托管：看她过一天（例子）

> **第 1 天 · 清晨**　她在公寓醒来（2 格）。
> **上午**　下楼吃早饭，梅把报纸推到她面前：莉莉安失踪（3 格，主线开启）。她问了一句，梅说莉莉安以前常一个人来吃早饭（好感 +2）。
> **午后**　去蓝鸟彩排（职业），卡斯在角落弹琴，不说话（1 格）。
> **傍晚**　精力不太够，回公寓躺了一会儿（一行字）。
> **夜晚**　登台唱晚场，小费 $1.20（2 格）。
> **深夜**　好奇心让她绕去了后巷。观察检定成功，捡到一只珍珠耳坠（3 格，获得线索）。保安远远看了她一眼（嫌疑度 +1）。
> **日记**　"那只耳坠，我在海报上见过。"

换一个种子，或者分身性格稍有不同，她可能深夜直接回家睡觉，第 3 天才从卡斯的报道里得知耳坠的事。

### 2.2 接管：亲手玩（例子）

> 你在第 2 天上午点「接管」，打开地图。码头上有个"!"（城市事件），餐厅有梅，片厂有伊莱。
> 你选择坐电车去码头（1 回合，$0.07）。到了以后，动作菜单里有：等人、观察、跟踪、和当铺老板说话。
> 你拿出耳坠问当铺老板。界面显示"口才 2，成功率 59%"，掷骰：部分成功。老板说上周有个女孩来当过一只一样的，但不肯说是谁（2 格）。
> 解锁新目标：「查出是谁当了另一只耳坠」。
> 你点「交还分身」，她接着去上班。

## 3. 时间

### 3.1 结构

| 时段 | 回合数 | 大致钟点 |
| --- | --- | --- |
| 清晨 | 2 | 6:00–8:00 |
| 上午 | 3 | 8:00–12:00 |
| 午后 | 3 | 12:00–17:00 |
| 傍晚 | 2 | 17:00–19:30 |
| 夜晚 | 3 | 19:30–24:00 |
| 深夜 | 2 | 0:00–3:00 |

每天 15 回合。每个动作占 1 回合，长动作（上班、登台、睡觉）占 2–3 回合。深夜之后自动睡觉，到第二天清晨。

### 3.2 时间控制

- **暂停**：看漫画、看地图，不推进。
- **正常**：一回合一回合推进，每件事出画格。
- **快进**：一直推进到下一个重要事件或决策。日常事件只记一行字，不出图。
- **过完今天**：快进到深夜，出当天的漫画和日记。

### 3.3 世界时刻表

有些事到点就发生，主角在不在场都一样：

| 时间 | 事件 | 不在场时怎么知道 |
| --- | --- | --- |
| 第 1 天上午 | 报纸登出莉莉安失踪 | 梅会提起 |
| 第 3 天上午 | 报纸登出莉莉安的照片 | 报摊、餐厅 |
| 第 4 天 | 罗南开始挨个问话（会来找你） | 他会再来 |
| 第 5 天夜晚 | 卡斯散场后在后门等你 | 他第二天会说"昨晚我等过你" |
| 第 7 天夜晚 | 凡斯家派对 | 第 8 天报纸 |

## 5. 人物

### 5.1 主角

- **需求**（0–100）：精力、心情、社交。
- **金钱**：初始 $12。参考物价：早饭 $0.25，电车 $0.07，出租 $0.50，一件像样的礼服 $8，一周房租 $5。
- **名气**（0–100）：登台、发稿、出现在派对上会涨。
- **嫌疑度**（0–5 级，类似 GTA 的通缉星）：打听、搜查、撒谎被拆穿会加分，每 10 分升一级；每天自然降 3 分。
- **技能**（1–5）：观察、口才、胆量，再加一项本职（唱歌、化妆或采访，按身份）。做相关的事会涨经验。
- **性格**（入住时生成，接管越多越像你）：好奇、谨慎、热情、骄傲等，每项 0–1。
- **物品和线索**：线索板上的卡片，可以组合推理。

### 5.2 常驻角色

每人有日程、性格、目标、秘密，以及和其他人的关系。日程按时段写，可以被故事卡临时改。

| 人物 | 日程（工作日） | 目标 | 秘密（编剧完善） |
| --- | --- | --- | --- |
| 梅 | 清晨–傍晚 餐厅；夜晚 自家 | 守住餐厅，照顾房客 | 莉莉安失踪前一周常一个人来吃早饭，说过"有人在跟着我" |
| 伊莱 | 上午 片厂；夜晚 蓝鸟；深夜 大宅 | 讨人喜欢，避开莉莉安的话题 | 莉莉安失踪那晚，他的车停在蓝鸟后巷 |
| 卡斯 | 午后–深夜 蓝鸟 | 保住饭碗，说出他看到的事 | 那晚他看见莉莉安上了一辆黑车 |
| 罗南 | 白天 各处问话；夜晚 码头附近 | 在上面逼他结案前查清真相 | 上面有人让他别碰凡斯家 |
| 薇薇安 | 午后 片厂；夜晚 大宅 | 保住女主角位置，保护莉莉安 | 她知道莉莉安为什么要躲 |

人物之间也有关系（好感、信任、怨恨）。他们之间会自己发生事情，主角可能事后才听说。

### 6.2 人物动作（举例）

| 动作 | 耗时 | 检定 | 效果 |
| --- | --- | --- | --- |
| 聊天 | 1 | — | 好感 +1–3，社交 +10 |
| 打听某件事 | 1 | 口才，信任修正 | 得到信息；信任不够会被搪塞 |
| 送礼 | 1 | — | 好感 +5–10，看礼物合不合心意 |
| 邀约 | 1 | 好感门槛 | 约好下个时段去某处，触发约会卡 |
| 恭维、调情 | 1 | 口才 | 好感 ±；在场的人可能吃醋 |
| 撒谎 | 1 | 口才，对方观察修正 | 成功则绕过；被拆穿则信任 -10，嫌疑 +3 |
| 威胁 | 1 | 胆量 | 拿到信息，但好感大降，可能报警 |
| 跟踪 | 1–2 | 观察、胆量 | 知道对方去哪；被发现则关系破裂风险 |

具体在哪能做什么、对谁能做什么，按地点、时段、关系和故事进度动态给出。

## 7. 检定

- **成功率** = 35% + 12% × 相关技能 + 修正（关系、精力、心情、物品、嫌疑度），限制在 5%–95%。
- **掷骰**（1–100）：不超过成功率为**成功**；超出 20 以内为**部分成功**（拿到一半，或者付出代价）；再往上是**失败**。三种结果都会推动剧情，失败也会产生故事。
- 接管时，动作按钮上直接显示成功率，比如"打听（口才 3，成功率 71%）"。
- 托管时同样掷骰，结果写进漫画旁白。

## 8. 自主决策（托管时她怎么选）

每回合把当前能做的所有动作（包括移动）打分，分数最高的几个里按权重随机选一个：

```
得分 = 需求收益（饿了吃饭、累了睡觉，越缺越重）
     + 性格加成（好奇 → 搜查、偷听；谨慎 → 回家；热情 → 聊天）
     + 任务牵引（目标相关的动作；离截止时间越近越重）
     + 像你（接管时你常选的那类动作）
     + 新鲜感（最近没做过的稍微加分）
     + 随机（0–10）
```

**决策点**（故事卡里的选项）按设置处理：

- **全交给分身**：按直觉概率选，沿用现在的做法；
- **重大决定等我**：主线和关系的关键选择停下来等你，其他自动；
- **每个都问我**。

默认是"重大决定等我"。

**像你**：记录你接管时每类动作的选择次数和决策点的选择，换算成权重。日记里偶尔会写"我越来越像那个会绕去后巷的人"，让你感觉到这一点。

## 9. 故事卡

### 9.1 格式

```json
{
  "id": "alley_earring",
  "title": "后巷的耳坠",
  "type": "main",
  "quest": "where_is_lillian",
  "once": true,
  "priority": 70,
  "when": {
    "place": "bluebird_backstage",
    "sub": "alley",
    "phase": ["night", "late"],
    "flags": ["main_started"],
    "not_flags": ["has_earring"]
  },
  "check": {"skill": "observe", "mod": 0},
  "beats_zh": {
    "success": "垃圾箱旁有一点珍珠光。是一只耳坠，和莉莉安海报上那只一模一样。",
    "partial": "她看见一只耳坠，刚捡起来，后门就开了，只好匆匆离开。",
    "fail": "巷子太黑，什么也没看清。保安从后门探出头来。"
  },
  "effects": {
    "success": {"items": ["earring"], "heat": 2, "unlock": ["pawn_stall"]},
    "partial": {"items": ["earring"], "heat": 5, "unlock": ["pawn_stall"]},
    "fail": {"heat": 4}
  },
  "render": {"importance": "major", "cast": ["user"], "cam": "close"}
}
```

| 字段 | 说明 |
| --- | --- |
| type | main（主线）、side（支线）、job（职业）、city（城市事件）、life（日常） |
| when | 触发条件：地点、次场景、时段、天数、谁在场、数值、关系、标记、物品 |
| priority | 同时满足多张卡时，先触发优先级高的 |
| once / cooldown | 只触发一次，或者间隔多少回合才能再触发 |
| check | 可选：要不要检定，用哪项技能 |
| choices | 可选：决策点，每个选项带后果和分身直觉权重 |
| beats_zh | 给 AI 演出用的要点，编剧写，AI 扩写成台词和分镜 |
| effects | 后果：数值、关系、物品、标记、解锁或关闭其他卡、推进任务 |
| render | 重要程度，决定画几格、要不要重绘或合成 |

### 9.2 触发规则

- 每回合结束时，找出条件满足的卡，按优先级取最多 1 张主线或支线卡和 1 张小事件卡。
- 没有卡触发、并且这一回合值得一看（比如到了新地点、遇到常驻角色）时，允许 AI 即兴补一个日常小事件。即兴事件**只能改心情、社交、好感 ±2 这类小数值**，不能给线索、不能推进主线。
- 编剧写骨架（条件、要点、后果），AI 起草台词和细节，编剧审过再入库。

## 10. 任务

### 10.1 结构

任务 → 阶段 → 目标。每个目标可以有多种完成方式，对应不同的故事卡。

### 10.2 第一章的任务

| 类型 | 任务 | 内容 |
| --- | --- | --- |
| 主线 | 莉莉安在哪 | 第一幕（第 1–2 天）：她最后一晚去了哪、她留下了什么、谁愿意说话；第二幕（第 3–5 天）：黑车、薇薇安、罗南的压力；第三幕（第 6–7 天）：派对、纸条、码头第三根灯柱 |
| 支线 | 梅的早餐客人 | 梅知道的事，信任够了才肯说 |
| 支线 | 伊莱的那一晚 | 伊莱的车为什么在后巷 |
| 支线 | 卡斯想说的事 | 他看见的黑车 |
| 支线 | 罗南的压力 | 帮他还是防着他 |
| 支线 | 薇薇安的警告 | 她在保护谁 |
| 职业 | 歌手：周六主唱 / 化妆师：薇薇安的专属化妆师 / 记者：头版独家 | 收入、名气，以及进入特定场合的资格 |
| 城市事件 | 码头的雾夜、片厂停电、报纸号外、电车罢工 | 随机，有的只出现一次 |

### 10.3 显示

- **地图标记**：主线黄色，支线蓝色，城市事件"!"，人物头像在所在地点。
- **任务日志**：当前目标、已知线索、截止时间。

## 12. 失败和结局

**会失败的事**

- 被解雇：连续上班失误，或者嫌疑度达到 4 级时被老板发现。解雇后可以找新工作，影响收入和进入某些场合的资格。
- 被警察带走问话：嫌疑度达到 5 级。损失一整个时段，罗南的信任重新计算。
- 被赶出派对：在大宅里搜查失败。
- 关系破裂：信任降到 0，对方不再见你，相关支线关闭。
- 错过线索：世界时刻表上的事不等人。

**第一章结局**（由几项状态组合决定，编剧细化）

| 结局 | 条件（示意） |
| --- | --- |
| 第三根灯柱 | 拿到纸条，并且自己去了码头 |
| 交给罗南 | 纸条交给罗南，并且罗南信任 ≥ 60 |
| 凡斯家的秘密 | 薇薇安信任 ≥ 70，派对上听她说出真相 |
| 被卷进去的人 | 嫌疑度 5 级，被当成嫌疑人带走 |
| 什么都没发生 | 主线目标完成不到一半，莉莉安的案子被草草结案 |

## 14. 技术架构

| 模块 | 文件（计划） | 说明 |
| --- | --- | --- |
| 模拟数据 | `content/sim.json` | 地点（区域、开放时段、动作）、人物（日程、性格、目标）、数值规则、移动方式 |
| 故事卡 | `content/cards/*.json` | 按任务分文件，编剧可以直接改 |
| 模拟内核 | `web/sim.js` | 时间回合、需求变化、日程、移动、动作结算、检定、自主决策、存档；用固定种子的随机数，同样的种子跑出同样的结果，方便调试 |
| 故事卡引擎 | `web/story.js` | 匹配条件、触发、执行后果、推进任务、判结局 |
| 演出 | 沿用 `engine.js` | 事件 → AI 分镜 → 拼接或重绘或合成 |
| 界面 | `index.html` | 托管时间轴、接管地图、动作菜单、状态栏、任务日志、线索板 |
| 导出 | `tools/export_world.py` | 把 `content/` 下的数据导出成页面能读的 js |

**AI 的用途**

1. 演出：每个重要事件一次，输入是事实，输出是 1–3 格分镜；
2. 起草故事卡细节（离线，编剧审）；
3. 即兴补位日常小事件（有限制）。

**花费估算**（未实测）：托管一天约 15 回合，其中约 8–12 件事出画格，大部分是拼接格。估计一天 $0.2–0.4。接管时动作多，会贵一些。

## 15. 里程碑

| 阶段 | 内容 | 验收 |
| --- | --- | --- |
| M1 模拟内核 | 时间回合、地点和移动、人物日程和需求、动作结算、检定、自主决策、存档。测试页上用文字日志跑，不出图、不调 AI | 托管跑 2 天：她的行程合理、有变化；换种子结果不同；常驻角色按日程出现 |
| M2 故事卡 | 卡引擎；第一幕 15 张卡；2 条支线；几个城市事件；任务日志 | 不同种子、不同性格跑出不同分支；主线第一幕至少两种走法 |
| M3 接管 | 地图界面、地点和人物动作、检定显示、线索板、状态栏、托管和接管切换 | 能亲手用两种方式完成第一幕 |
| M4 漫画演出 | 事件转分镜，分级出图，时间轴，时间控制，决策点设置 | 托管一天的漫画连贯好看；接管时每个动作当场出格 |
| M5 第一章 | 写完 7 天的卡，多结局，数值平衡 | 第一章完整可玩，至少 4 种结局可达 |
| 之后 | 现实时间模式 | 离开期间世界按真实时间继续，回来看今天的回顾 |

现在的玩法（按时段写剧情）在 M4 完成前保留，作为"旧版"入口。

## 16. 待定和风险

- **内容量**：高自由度要大量故事卡。第一章估计需要 80–120 张，其中主线和支线约 50 张由编剧写骨架。
- **平衡**：数值和检定概率要靠 M1–M3 反复跑来调。测试页会提供"用同一个种子跑 100 天"的统计。
- **AI 演出的一致性**：AI 只写台词和分镜，不能改事实。输出要校验：出场的人必须在场，物品必须存在。
- **出图节奏**：托管一天出 8–12 件事的画格，需要沿用预生成和后台提前出图，才能保持秒出。
